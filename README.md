# Reinier&Dianko - Tienda de Moda Online

![Reinier&Dianko](https://images.unsplash.com/photo-1483985988355-763728e1935b?w=1200&q=80)

## 🛍️ Sobre el Proyecto

Sitio web de moda profesional y minimalista para Reinier&Dianko, un negocio de moda ubicado en Cienfuegos, Cuba. El diseño está inspirado en marcas de moda reconocidas como Zara y Massimo Dutti, priorizando imágenes de alta calidad y una experiencia de usuario elegante.

## ✨ Características

- 🎨 Diseño minimalista y profesional
- 📱 Totalmente responsive (móvil, tablet, desktop)
- 🖼️ Imágenes de alta calidad de Unsplash
- 🛒 Sistema de carrito de compras interactivo
- 📧 Formulario de newsletter funcional
- 🎯 Animaciones suaves y profesionales
- 🔍 Navegación intuitiva
